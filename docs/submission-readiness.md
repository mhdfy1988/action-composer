## 工作台模块边界

| 模块                               | 拥有的职责                                                                           | 不拥有的状态                               |
| ---------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------ |
| `application/workspace.js`         | 装配模块、当前动作／帧、范围、显隐、共同刷新和任务互斥；协调对齐、历史与键盘入口     | 导入草稿、播放时钟、手势细节               |
| `application/import-controller.js` | 连接导入弹窗、无DOM导入用例与共同任务；接收结果后更新选择及状态反馈                  | 弹窗内部节点、素材构造与第二套历史         |
| `application/import-frames.js`     | 无DOM导入用例：解码／切片、预算、动作构造、一次提交；失败释放本次资源，成功移交media | 页面节点、选择和状态文案                   |
| `application/export-controller.js` | 接收导出参数快照，组织共同任务、输出服务与下载                                       | 弹窗节点、动作本身名称、预览显隐规则       |
| `application/action-commands.js`   | 改名及动作／帧删除确认、复制命令；调用弹窗公开接口，通过回调协调选择                 | 弹窗内部节点、当前选择、图片副本、独立历史 |
| `application/playback.js`          | 共同时间起点、暂停状态与单一动画循环，支持停止调度                                   | 动作数据、所选帧与编辑事务                 |
| `ui/stage-interaction.js`          | 命中、捕获、平移／缩放／拖动意图；通过会话预览接口更新和确认，取消不提交             | 正式数据替换、草稿真值和历史系统           |
| `ui/inspector.js`                  | 参数模板、投影、横纵／尺度输入和范围切换意图                                         | 工具栏节点、播放时长、范围业务真值         |

### 界面结构与样式

| 组件／入口                                    | 当前职责与协作接口                                                                            |
| --------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `index.html`、`ui/workspace-shell.js`         | 文档入口与区域装配；页面壳不构造面板内部控件                                                  |
| `ui/header.js`、`ui/library.js`               | 顶栏导入／导出意图，动作列表的选择、显隐和命令；动作增量渲染仍复用action-list，播放不重建节点 |
| `ui/toolbar.js`、`ui/viewport.js`             | 工具栏投影与操作意图；画布空状态、观察比例和尺寸观察。Canvas作为舞台及手势适配的显式表面      |
| `ui/inspector.js`、`ui/timeline.js`           | 参数与范围、播放与时长输入、帧带及状态反馈；帧卡片仍复用Filmstrip，不另存业务真值             |
| `ui/import-dialog.js`、`ui/import-order.js`   | 文件入口、清单准备、排序与切片预览；确认发出输入并移交源图，取消清理临时资源，不自行提交会话  |
| `ui/export-dialog.js`                         | 输出选项与表单验证，确认一次性传出名称、范围、格式、列数和留白快照                            |
| `ui/rename-dialog.js`、`ui/confirm-dialog.js` | 名称输入、确认／取消和初始焦点；调用方只使用open接口，不访问内部节点                          |
| `ui/dom.js`、`ui/icons.js`                    | 仅源码静态模板的构造与根内节点引用、本地图标；动态名称用textContent／value，不拼入模板        |
| `ui/styles.css`、`ui/styles/`及同名组件CSS    | 样式入口只组织导入；基础变量、控件和弹窗外壳共享，局部规则按组件归属维护                      |

组件保留原ID以维持标签关联和正式入口测试，但查询限定在所属根节点。工作台不再逐项填充兄弟组件字段，控制器不通过全局ID接线；键盘入口仍可判断是否有模态弹窗打开。所有权不要求每个小控件各建一层，当前没有新增框架、组件库或第二套状态系统。

`Session` 拥有项目元数据、普通历史、范围回溯及独立预览草稿。`project` 始终是正式数据，`viewProject` 在预览期间提供草稿。预览令牌标识一次手势，每次更新从正式基线重算；确认经既有edit校验并提交一次，取消不改正式数据和历史。过期令牌不生效，普通edit拒绝未结束预览；历史切换使预览失效。工作台在其他编辑／任务开始前结束当前手势。

导入执行接受文件、时长、名称、帧率、可选切片方案与源图、取消信号及进度回调。使用现有解码、切片和预算适配，独立测试可传入对应实现。执行期间素材仅归本次导入，成功时一笔提交并移交媒体集合，失败／取消释放新位图和源图；等待期间正式会话变化也拒绝提交。成功素材由会话级媒体集合继续保留，避免撤销引用被提前释放。页面反馈与选择由控制器处理，现有领域运算、导出几何和校验器保持唯一实现。

修改导入行列、取消和预览位图释放从导入弹窗进入；解码、预算与正式提交从导入用例进入；改播放时间从播放模块进入；改参数投影从参数面板进入。接口显式接收必要上下文和操作，不依赖浏览器按DOM id暴露的隐式全局变量。工作台保留跨模块协调，不为减行数再拆空壳。

这些边界面向当前单工作台。完整宿主挂载／卸载契约、插件接入及新增多层能力仍属后续工作，不能因播放模块具备dispose方法就宣称整个工作台支持插件生命周期。
