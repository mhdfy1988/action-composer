## 准备与使用

在项目根目录执行；先按项目 README 启动 8914。

```powershell
$env:ACTION_COMPOSER_REAL_FIXTURE='D:\learn_code\game\reference-compare-demo\assets'
node experiments/registration/prepare.mjs
```

准备脚本复用正式构建的 OpenCV 4.13.0 准备入口（约 10.5 MiB，包含 WebAssembly），核对 SHA-256 后缓存在 `.cache/opencv` 并复制至 dist。先启动／构建项目以生成共用 Worker。素材来源仅从显式环境变量读取，复制原 PNG 到 `output/registration-lab`，不上传、不改源文件。不设置环境变量则仅准备运行库，可在页面导入自己的素材。

用 Chrome 打开实验页。默认载入本机示例并框选完整前景（alpha≥200 范围加 2 px），包含头顶和脚底；“全身”按钮恢复该范围，也可手拉框调整。头部／躯干入口仅作辅助对照。设倍率范围，点击“计算首帧匹配”。在“轮廓对齐”和“区域匹配”之间切换，查看叠加和后续帧；双方始终共用参照原图坐标。初始倍率 1.5–4 仅适用于本次浣熊样例，不是自动识别范围。

右侧“首帧全身检查”随当前对照方法显示整幅前景轮廓的高度差百分比、顶部与底部偏差（参照原图像素）。始终测量首帧，不因播放跳跃而重新拟合；切换局部框也不将局部高度冒充全身高度。该测量并非人体标点识别，长尾、武器等仍可能影响范围。匹配仍只求统一缩放与平移，不强制将选框拉成一样大。

仅支持 PNG，单图 20 MB／400 万像素，动作最多 24 帧、48 MB／2400 万像素，组内原图尺寸必须一致；这是实验约束，不改变主应用协议。示例“头部／躯干”是本机图片上的人工预设框，不是人体识别。

## 算法来源与边界

核心匹配直接调用官方 OpenCV `matchTemplate(..., TM_CCORR_NORMED, mask)`、`minMaxLoc`，并非重新手写相似度公式。项目代码只负责区域选取、多尺度粗细搜索、透明掩膜、参数坐标映射和实验界面。

1. 双方原图通过 Canvas 解码，透明 RGB 不作为背景纹理；参照 ROI 的 alpha≥200 像素形成掩膜，再内缩 1 px。
2. 选择灰度纹理，或 Sobel 灰度梯度幅值；不将轮廓框当身体特征。
3. 目标工作图最长边缩至 460，模板按倍率缩放搜索。45 档对数粗搜索，再在最佳档附近细搜 17 档；不穷举所有尺度，也不允许旋转、剪切和非等比拉伸。
4. 对每个倍率调用归一化相关匹配；剔除 NaN／Inf 和有效前景重叠不足 85% 的位置。全透明／无纹理区域拒绝。候选接近倍率边界会提示重算。
5. 输出 `referencePoint = targetPoint * scale + (tx,ty)`。只拟合首帧，全部帧复用，不做逐帧去位移。计算在 Worker 中进行，取消销毁 Worker，旧实例结果不得发布到新实例。

分数是对应表示下的相似度，不是成功概率；灰度与梯度分数不能横向作为同一置信度比较。0.7 警告线是实验提示值，未经角色数据集校准；重复纹理、局部重画、姿态差异仍可能出现高分错误匹配。透明前景掩膜也不是双边掩膜配准的完整实现。

## 本机实验结果

已知合成图是源图放大 2 倍、平移 `(32,16)` 生成；结果约为尺度 `2.00513`、平移 `(31.65,15.67)`。验证允差为尺度 0.03、平移每轴 2 px，不称为无误差配准。

| 浣熊首帧策略 | 整组倍率 | 区域相关分数 |
| ------------ | -------- | ------------ |
| 原轮廓对齐   | 2.72875  | 不适用       |
| 全身／梯度   | 2.65564  | 0.56887      |
| 全身／灰度   | 2.66305  | 0.94052      |
| 头部／梯度   | 2.54693  | 0.71810      |
| 头部／灰度   | 2.52573  | 0.97632      |
| 躯干／梯度   | 2.61890  | 0.73521      |
| 躯干／灰度   | 2.61890  | 0.96927      |

人工审阅：头脸或躯干可获得较好局部重合，但脚部仍有重影；不同区域得到不同倍率，不能认定模板匹配自动解决全身比例。用户选择以全身匹配配合人工调整，正式工具现已按此接入；不会自动确认或用局部高分自动发布整组。后续仍需更多角色、姿态与基点约束验证。

原始 JSON、叠加截图与合成误差记录均在 `output/registration-lab/`，包含私人图，不分发。验证命令：

